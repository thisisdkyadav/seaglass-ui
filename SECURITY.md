# Security policy

## Supported versions

Security fixes are released for the latest minor version of `seaglass-ui`.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/thisisdkyadav/seaglass-ui/security/advisories/new).
You will get a reply within a few days, and a fix or mitigation plan as soon as the issue is confirmed.
